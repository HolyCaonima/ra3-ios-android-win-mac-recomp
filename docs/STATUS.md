# 状态与证据边界

整理日期：**2026-11-15**。来源是维护者的开发记录与实际操作反馈，原始日志和材料不随公开版发布。本表不是第三方认证，也不是本仓库 CI 能复现的游戏验证。

| 范围 | 已记录结果 | 不据此宣称 |
| --- | --- | --- |
| Windows 1.12 | 开发者完成一局遭遇战 | 所有任务、Mod、长期稳定性均通过 |
| Android 1.12 | 进入战场、选中建造场；菜单、片头音频和触摸坐标已有检查 | 完整一局、新公共补丁全部在 Android 真机通过 |
| macOS 1.12 | 菜单、战场、地形/HUD、键鼠、动画光标 | 整局、所有 D3D9 路径、独立可分发应用 |
| iPad 1.12 | 对局可操作；GPU 生命周期候选修补后一轮真机复测通过 | 所有设备/场景稳定，性能无代价 |
| iPad ↔ Mac LAN | 观察到双向房间发现 | 成功入房、完整联机、Wi-Fi 路径或原版 Windows 互通 |
| 公开工具 | 合成图像差异、配置选择和发布守卫可独立验证 | 游戏或完整重编译系统已经开源 |

## 保留的问题

- ARM64 普通访存的完整 x86 内存序保证尚未建立。
- Android 后台返回的窗口恢复及完整对局仍需专项验证。
- 部分图形能力、验证器告警和平台差异需要继续处理。
- iPad GPU 修补的长期稳定性、管线变体增长和资源保留成本仍需测量。
- 局域网发现与真正的游戏会话是不同阶段；后者没有完整验证结果。
- 1.12 的结果不能自动外推到其他游戏版本。

## 后续公开方向

首先维护公开工具、补齐合成边界测试和方法说明。其他通用模块只有在完成依赖拆分、来源确认、脱敏及独立验证后才考虑发布。不会用“以后补许可”作为先上传代码的理由，也不承诺公开任何游戏派生物。
