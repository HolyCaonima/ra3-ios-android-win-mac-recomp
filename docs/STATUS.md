## 保留的问题

- ARM64 普通访存的完整 x86 内存序保证尚未建立。
- Android 后台返回的窗口恢复及完整对局仍需专项验证。
- 部分图形能力、验证器告警和平台差异需要继续处理。
- iPad GPU 修补的长期稳定性、管线变体增长和资源保留成本仍需测量。
- 联机公开视频已展示进入游戏会话，但未展示整局完成；长期同步稳定性仍需验证。
- 1.12 的结果不能自动外推到其他游戏版本。

## 后续公开方向

已增加资源工具、lifter 扩展、独立宿主组件、DNS-SD 桥接和图形补丁；继续拆分其余原创运行时与平台集成，明确来源、依赖和验证范围。游戏资源本体与生成的 lift C 继续排除。
