# 首次公开版本的整理与复核

本版本在独立目录中建立，使用全新 Git 历史；没有从开发仓库 clone、复制 `.git` 或迁移 LFS 内容。

## 选择结果

| 类别 | 处理 |
| --- | --- |
| 架构、方法、平台经验、状态 | 阅读开发记录后重新撰写，去除机器路径、设备标识、私有地址和原始诊断内容 |
| 通用 CMake 配置 | 抽出配置选择与两个模板，移除游戏版本字段；用独立示例验证 |
| 图像差异统计 | 整理为独立 CLI；测试只在临时目录创建合成图片 |
| 公开检查与测试 | 此次新写；不读取开发仓库 |
| 兼容层、翻译器扩展、原生替换、第三方补丁 | 本批未发布，避免混入来源复杂或依赖专有数据的实现 |
| 游戏、资源、生成源码、授权相关功能、设备材料 | 全部排除 |

`PUBLICATION.json` 精确列出每一个公开路径及其来源类别。清单覆盖文档、代码、测试、许可证和 CI；它是审查记录的索引，不是自动版权证明。

## 本地发布步骤

```sh
python -B tools/verify.py
git diff --check
git diff --cached
python -B tools/publication_guard.py --index
```

只暂存清单中的具体路径。完成提交后，再运行 `python -B tools/verify.py` 检查包含新提交的历史，确认目标远端正确后再推送。不要把原开发仓库添加为推送来源，不要上传其历史或 tags。

## 自动检查覆盖什么

- 精确路径白名单，禁止符号链接、子模块和异常文件模式。
- 单文件大小、UTF-8 文本、控制字符、可执行/压缩文件头及 LFS 指针。
- 常见凭据、私钥、个人主目录路径和部分机器生成游戏符号模式。
- 工作目录、Git 暂存区和所有本地引用可达的提交快照；历史使用本次审查清单，不信任历史中的自带清单。
- 合成负例：未批准路径、伪装二进制、凭据、符号链接、已删除的历史泄漏、暂存内容与工作区不同等。

本地 `.venv/` 仅在工作目录遍历时忽略；若出现在 Git 索引或历史中仍失败。其他额外文件（包括缓存、构建输出和截图）会被拒绝，测试产物都写入仓库外的临时目录。

## 局限

正则和扩展名无法识别全部秘密、授权码、第三方表达或经过编码的数据；白名单也可能被错误修改。检查器、清单和工作流的更改必须人工审阅。CI 在内容上传后才运行，不是防止第一次公开泄漏的屏障。

历史检查只覆盖本地可见的 refs；远端独有 refs、PR 附件、Release 附件及其他服务中的内容不在范围。浅克隆被拒绝，应取得完整历史后检查。本次初始化不创建游戏发行附件或 Release。

## 许可检查

使用标准 MIT 文本；没有添加非商业用途限制。本次不捆绑第三方代码，外部依赖独立安装。未发现所选通用文件中的第三方署名或专有数据；这项审查不能保证发现所有潜在权利问题，来源有疑问的候选内容没有纳入本次发布。
